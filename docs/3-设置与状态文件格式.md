# 设置与状态的格式

工具 `LdacConfig` 负责写入，编码服务 `LdacSvc` 负责读取并即时应用变更（每秒检查一次文件的修改时间）。

## `%ProgramData%\LdacA2dp\settings.json`

```json
{
  "devices": {
    "66:77:88:99:AA:BB": {
      "driver": "Ldac",
      "codec": "LDAC",
      "allowMono": false,
      "allowStereo": true,
      "rate44": true, "rate48": true, "rate88": true, "rate96": true,
      "bits16": true, "bits24": true,
      "channelMode": "Stereo",
      "quality": "SQ",
      "adaptive": true,
      "holdSeconds": 3
    }
  }
}
```

与 `a2dp_prefs`（`avdtp/include/a2dp_codec.h`）的对应关系：

| 字段 | `a2dp_prefs` / 编码器 |
|---|---|
| `codec` = `SBC` | `allow_ldac = 0` |
| `rate44/48/88/96` | `ldac_freq_mask`（`LDAC_FREQ_*`）；`ldac_pref_rate` = 允许的最高采样率 |
| `allowMono`、`allowStereo` + `channelMode` | `ldac_cm_mask`：Stereo → `LDAC_CM_STEREO`，Dual Channel → `LDAC_CM_DUAL`，单声道 → `LDAC_CM_MONO` |
| `bits16/24` | `ldacBT_init_handle_encode` 的输入 PCM 格式（`S16`/`S24`） |
| `quality` | `LDACBT_EQMID_MQ/SQ/HQ`，可通过 `ldacBT_set_eqmid` 即时切换 |
| `adaptive` | `ldac_ABR_Proc(..., flagEnable = 1)` |
| `holdSeconds` | 在 Windows 流已关闭后，最后一次有声音之后还需将流保持在 START 的秒数（1–600，默认 3）。只要 Windows 流处于打开状态，即使没有该设置也会保持发送 |

该工具不允许取消组内最后一个勾选项，因此文件中不会出现空掩码。

## `%ProgramData%\LdacA2dp\status\<AA-BB-CC-DD-EE-FF>.json`

服务在服务耳机期间每秒写入一次，并在会话结束时删除。工具每秒轮询该文件，并在「当前状态」一节中显示。若文件超过 5 秒未更新，工具即认为没有数据。

```json
{ "codec": "SBC", "channelMode": "Joint Stereo", "sampleRate": 48000, "bitDepth": 16, "bitrateKbps": 357,
  "streaming": false, "quality": "bp53", "droppedPackets": 0,
  "avrcp": "absoluteVolume", "absoluteVolume": true, "volumeDb": -17.8, "muted": false }
```

| 字段 | 取值 |
|---|---|
| `streaming` | 流处于 START（有声音，或暂停中传输静音），否则为 SUSPEND |
| `quality` | 编码器当前档位：LDAC 为 `HQ`/`SQ`/`Q0`/`Q1`/`MQ`（ABR），SBC 为 `bp<bitpool>` |
| `droppedPackets` | 本会话中服务未能放入驱动队列的包数 |
| `avrcp` | `none`（无 AVRCP 设备）、`closed`、`opening`、`connected`、`absoluteVolume`、`noAbsoluteVolume` |
| `absoluteVolume`、`volumeDb`、`muted` | 端点的音量以及由谁应用：耳机（AVRCP）或服务 |

服务自身的状态（运行中、已停止、未安装）由工具从服务管理器中获取。
